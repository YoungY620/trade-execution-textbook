# 订单簿、订单类型与隐匿执行

执行计划总会走到一个它自己不做决定的地方：用哪种订单、挂在哪一档、显示多少、挂到哪个场所。这些选择既决定了前几章建模的成本，也决定了执行者意图有多少会被别人读出来。

## 订单类型及其成本结构

市价单买的是即时性：它以对手方最优报价成交，付出半个价差加交易所手续费，超过盘口数量后还会推动价格。按 Cont 与 Kukanov (2017) 的记号，$h$ 是挂单时刻的**半个买卖价差**，$f$ 是市价单手续费，数量为 $M$ 的市价单相对中间价的成本在冲击之前是 $(h+f)M$。

限价单用即时性换价格改善：成交时赚到 $h$ 加上**有效返佣** $r_k=r_k^{e}+AS_k$，即交易所返佣 $r_k^{e}$ 再扣掉 $AS_k$——该场所特有的逆向选择惩罚，通常取一笔限价单成交后短窗口内的平均收益。两项风险抵消了这笔收益：到期未成交，以及成交恰恰是因为价格正要朝持仓反方向走。Cont 与 Kukanov 把它们写成每股价的惩罚项 $\lambda_u$（未达目标量 $S$）与 $\lambda_o$（超出 $S$）。

**冰山单**只显示小于总量的峰量，每个峰成交后自动从隐藏部分补出新的峰；**隐藏单**则完全不显示。两者在相同价位上都让位于显示单——在 Xetra 上，显示单无论提交时间先后都优先于隐藏单。换来的是整个数量不摆在盘口上被人读取和抢单。

条件单与时间加权单（到达量、参与率、VWAP/TWAP 目标）是调度工具，它们固定切片，再由下面的挂单问题决定如何路由。两层会互相影响：Cartea 与 Jaimungal (2016) 表明，当执行者自己的成交与市场的市价单到达同向对称时，最优速度应随预期的净订单流变化。

## 限价单与市价单的拆分

Cont 与 Kukanov (2017) 固定一个在 $[0,T]$ 内买入 $S$ 股的切片，把调度视为给定，选择 $X=(M,L_1,\dots,L_K)$：一个市价单，以及每个场所一个挂在全美最优买价、排进长度为 $Q_k$ 队列的限价单。令 $\xi_k=C_k+D_k$ 为队列 $k$ 前端的流出量——撤单加上到达该场所的市价单——于是该限价单成交 $\min(\max(\xi_k-Q_k,0),L_k)$ 股。其成本函数在成交的限价单上收回有效返佣，在每股市价单上计入价差与手续费，并对全部挂出数量收取线性冲击 $\theta$，$\lambda_u,\lambda_o$ 是欠交与超交的每股价惩罚。在三个约束 $\min_k r_k+h>0$、$\lambda_o>h+\max_k r_k$、$\lambda_u>h+f$ 之下，目标函数凸、有下界且有全局最优解：单一订单不会超量，但**总和**可以刻意超过 $S$。

只有一个场所时拆分有闭式解（其命题 3）。当 $\underline{\lambda_u}<\lambda_u<\overline{\lambda_u}$ 时，

$$L^{*}=F^{-1}\!\left(\frac{2h+f+r}{\lambda_u+h+r+\theta}\right)-Q,\qquad M^{*}=S-L^{*},$$

其中 $F$ 是队列流出量 $\xi$ 的分布函数，$F^{-1}$ 为其左逆。分位数水平是边际成本与边际节省之比：多挂一股市价单要付 $h+f$，又因 $M+L=S$ 而放弃该股被动挂单本可赚到的 $h+r$，即分子 $2h+f+r$；反过来，限价单不成交就要以 $\lambda_u+\theta$ 的代价追补，即分母。在阈值之外由角点解接管：低于 $\underline{\lambda_u}$ 全用限价 $(0,S)$，高于 $\overline{\lambda_u}$ 全用市价 $(S,0)$。短期观点越强，$\lambda_u$ 越大，$L^{*}$ 越小，穿越价差越多。

有三点与隐匿直接相关。最优点取决于**完整分布** $F$ 而非其均值，因为成交来自尾部 $\Pr(\xi>Q+L)$。限价单容量**有界**：$S$ 增大时 $L^{*}$ 不再增长，多出来的量只能走市价单，因为要吃掉一笔大限价单需要不现实的巨大流出量。跨场所时最优点**使各场所的欠交概率相等**（其命题 4），挂出的限价总量超过目标量——这是一种刻意"超额预订"，且因各场所成交不完全相关而随场所数增加。这正是"幻影流动性"的理性解释：可见订单簿高估了真实执行意图，而并没有人在虚假挂单。

## 队列位置的价值

Moallemi 与 Yuan (2016) 给"排在前面"定了价。在价格—时间优先下，挂单的期望价值分解为 $V_t=\alpha_t(\delta_t-AS_t)$：$\alpha_t=\Pr(\text{成交}\mid\mathcal F_t)$ 是成交概率，$\delta_t$ 是流动性溢价（挂单价减潜在有效价，当潜在价等于中间价时即为半个价差），$AS_t=\mathbb{E}[P_{\tau^*}-P_t\mid\text{成交}]$ 是逆向选择成本。把成交、价格跳变与撤单建模为泊松事件，状态记为 $(\delta,q)$（$q$ 为队列位置），价值函数对溢价是拟线性的：

$$V(q,\delta)=\alpha(q)\delta-\beta(q).$$

成交概率 $\alpha(q)$ 随队列位置下降，因为队列按顺序消耗；逆向选择成本 $\beta(q)/\alpha(q)$ 随 $q$ 上升，因为长队尾部的订单更可能被大额知情单吃掉。成交量为双边指数分布时可解出
$\alpha(q)=p_J^++\frac{\mu(1-p_J^+)}{\mu+2\gamma}e^{-bq}$，
$b=(\gamma+\zeta)\theta/(\mu/2+\gamma)$，价值随位置指数衰减。以 BAC 校准，2013-08-09 队首比平均队列位置多值约 0.26 tick，2013-08-20 多值 0.21 tick——与整个价差同量级。

## 显示多少

显示是时间优先与暴露之间的取舍。Cebiroğlu 与 Horst (2011) 让冰山执行者选择显示量 $\Delta\in[0,N]$，且只通过盘口不平衡 $I(\Delta)$（随 $\Delta$ 递增）影响市场。多显示一股的边际效应分为两项：

$$\frac{d}{d\Delta}W\coloneqq M_{\mathrm{Market}}-M_{\mathrm{Priority}},$$

其中 $M_{\mathrm{Priority}}$（时间优先带来的收益）一定是成本下降，而 $M_{\mathrm{Market}}$（经不平衡作用于流量与价格的暴露冲击）方向不定。若 $W$ 严格凸且最优内点，则
$M_{\mathrm{Market}}(\Delta^{*})=M_{\mathrm{Priority}}(\Delta^{*})$：一直显示到市场对你可见度的反应正好抵消你换来的队列位置。当暴露被市场奖励时，全显示 $\Delta^{*}=N$ 最优；对大单符号反转，超过某规模 $N_d$ 且价格因暴露而偏离时，$\Delta^{*}=0$（全部隐藏）。以 NASDAQ 数据校准，暴露冲击主要通过竞争性（"抢先"）限价单流与对手方最优报价传导，而非市价单流，冰山单相对普通限价单最多可降低 60% 执行成本——但只对大单、且主要在不平衡偏向自己一侧时成立。

隐藏是一场被发现的博弈。Frey 与 Sandås (2009) 给出实证：在 Xetra 上冰山单可被识别——某个峰成交后，同价位的新峰会出现在队尾；峰量与已成交峰数可用于预测隐藏量。冰山单约占提交非市价单的 9%、成交股数的 16%，规模是普通限价单的 12–20 倍。被识破的冰山单**吸引**而非排斥市价单，与"帮助寻找潜在流动性"一致；且已成交比例越高，价格冲击**越小**，说明隐藏流动性更可能是无信息的。

理论给出同样的"越大越要藏"结论。Buti 与 Rindi (2009) 让交易者同时选择价格、数量与**暴露**，发现隐藏单是均衡策略：早期用于阻止被降价抢单，并选择刚好阻止抢单的最大显示量；引入快速交易者与**被抢单风险**后，隐藏单在两个节点都最优，挂在第二档，并尽量多藏。隐藏单使用随订单规模与对手方相对深度上升，随冲击临近时间下降。Moinas (2010) 用另一条路径得到相同方向：比较不透明与透明订单簿，知情者与大额无信息供给者都会隐藏，因为显示大单会赶走透明簿本可吸引来的无信息对手方，因此交易前的不透明提高流动性与福利。

现代数据使画面复杂。Chakrabarty、Hendershott、Nawn 与 Pascual (2019) 发现高频交易者大量使用隐藏限价单，但方式**与理论相反**：其隐藏单很小、贴近最优报价、且是各类交易者—订单类型组合中信息含量**最低**的。免费期权理论与信息延迟披露理论都解释不了，作者转而验证两个猜想——用非显示标志在不暴露自身的情况下抢在既有报价之前，以及在短期波动高峰前抢位。最优报价附近约 30%（低波动日）到 50%（高波动日）的 Nasdaq 盘口是隐藏的。隐藏不等于知情。

## 两种不透明

隐藏单与暗池是不同产品。Degryse、Tombeur 与 Wuyts (2015) 用荷兰大盘股的毫秒数据发现：隐藏单成交占比在高成交量日更高，而暗池占比反而**更低**（成交量大意味着即时性需求大，撮合场所更受青睐、隐藏单成交概率上升）；波动率对两者都无影响但压低大宗交易；隐藏单交易随可见深度下降（可见深度享有优先权），暗池则不受影响。两者是**替代品**，但暗池对隐藏单的替代强于反向。

Foucault、Kadan 与 Kandel (2005) 把限价订单簿理解为**流动性的市场**：有耐心的交易者挂单，急迫的交易者穿越价差，由等待成本排序；耐心异质时存在切平价差 $s_c\in(j_p,K)$，在此之上所有交易者都挂单。限价单的期望等待随它制造的价差上升，$T^{*}(j)>1/\pi$，因为价差越宽队列优先级越低。

Zhu (2014) 追问暗池对价格发现的作用。知情单方向一致，因此在暗池中比不相关的流动性订单面临**更低**的成交概率——撮合中的"赢家诅咒"。存在唯一波动率阈值 $\bar\sigma$：低于它知情者留在交易所但配比改变，高于它知情者完全回避暗池。加入暗池会严格降低流动性交易者的交易所参与率与知情总量、并抬高价差，却因把与价格相关的信息集中到交易所而**改善**价格发现——这与监管直觉相反，结论依赖于流动性交易者内生选择场所。

## 信息泄露与掠夺性交易

暴露的订单不只是可见，而是可被利用。Brunnermeier 与 Pedersen (2005) 让一部分交易者面临困境与在 $T$ 前的清算期限，价格含线性冲击 $p(t)=v+\lambda\int_0^t\sum_i a^i(u)\,du$。其命题 1 给出单掠夺者均衡：每个困境者以 $A/I$ 的匀速卖出 $\tau=x(t_0)/(A/I)$ 期，掠夺者在同期以不产生临时冲击的最快速度同向卖出，随后买回。价格**过冲**，困境者的超额清算成本等于掠夺者的利润；市场恰在最需要流动性时最不流动，因此披露持仓等于公告冲击会发生在哪里。

订单流的信息含量可以实时度量。Easley、López de Prado 与 O'Hara (2012) 定义 **VPIN**（成交量同步的知情交易概率）：把交易日切成等成交量桶，规模 $V$、编号 $\tau=1,\dots,n$，$V_\tau^{B},V_\tau^{S}$ 为批量分类下的买、卖量，则

$$\text{VPIN}=\frac{\alpha\mu}{\alpha\mu+2\varepsilon}\;\approx\;\frac{\sum_{\tau=1}^{n}|V_\tau^{S}-V_\tau^{B}|}{n\,V},$$

按成交量时间滚动更新，基线取 $V$ 为日均量的 1/50、$n=50$。E-mini 标普 500 期货上，CDF(VPIN) 在 2010-05-06 闪崩前至少两小时越过 0.9。它告诉挂单者订单流已经变毒。

隐匿策略会留下脚印。Stenfors 与 Susai (2021) 研究 EBS 上 EUR/USD 的 1,419,630 笔限价单，把**拆单**定义为：某单价格与另一笔同向订单相同、两者提交间隔小于 0.1 秒、其间无其他挂单或撤单——人类达不到这个阈值。约 17.42% 的订单是拆单。拆单比非拆单更激进，所以拆单也用于改善价格而非仅隐藏规模；但在给定规模下，拆单触发**更多**流动性撤回、被认为更具冲击力。短期内拆单在隐匿目标上适得其反。算法先对对手方免费期权风险反应，人类反应之后同侧未成交风险对大单占主导。

## 持有私有信息的执行者该怎么做

文献支持一批具体做法，也对另一些保持沉默。

- **用欠交分位数决定拆分。** 挂出 $L^{*}=F^{-1}\!\big(\frac{2h+f+r}{\lambda_u+h+r+\theta}\big)-Q$，其余穿越价差：提高 $\lambda_u$ 会把量推向市价单，队列越长限价切片越小，跨场所时应使欠交概率相等。
- **为队列价值而挂盘口。** Moallemi–Yuan 把大盘股队首定价为 0.21–0.26 tick，接近整个价差，因此挂单本质上是优先级决策。
- **订单越大，显示越少。** Cebiroğlu–Horst 与 Buti–Rindi/Moinas 方向一致；Cebiroğlu–Horst 对大单、且不平衡利于自己时给出最高 60% 的改善。
- **默认隐藏会被识破。** Frey–Sandås 靠补峰模式识别冰山单，识别后它反而吸引市价单；Chakrabarty 等显示非显示标志本身就被博弈。隐藏减少的是披露，不是可见性。
- **不要以为拆单是免费隐匿。** Stenfors–Susai 测出拆单比同等人类订单更具冲击力。拆单只有在配合随机化时间、规模与场所时才可能有用——而把参与率、随机化与拆单粒度对着一个探测模型做联合优化，**文献未直接回答**。
- **把暗池与隐藏单当替代品而非重复品。** Degryse 等发现二者对市场条件反应不同，且暗池是更好的替代品，应按当前成交量、深度与价差选择其一。
- **要对掠夺者建模，而不只是对订单簿建模。** Brunnermeier–Pedersen 说明可观测的清算需求会被抢跑，因此应隐藏方向与规模、避免被迫清算的脚印；这种隐匿收益随紧迫度如何变化，**文献未直接回答**。
- **盯着订单流毒性。** VPIN 可在成交量时间上实时计算并提前两小时预警闪崩，可用于调节挂单位置与显示量。

文献未解决的开放问题：冰山最优显示量与同时可用的暗池如何互动；以及 Cebiroğlu–Horst 的 60% 改善在扣除 Frey–Sandås 所测冰山后方限价单的时间优先与逆向选择成本后是否仍然成立。Esser–Mönch (2007)、Cartea–Jaimungal (2015)、Yang–Zhu (2020) 本章未能获取，未据其结论立论。

## 本章要点

- 市价单用半个价差加手续费与冲击换取即时性；限价单赚半个价差加有效返佣，但承担未成交与被逆向选择的风险；冰山单与隐藏单让出时间优先以隐藏规模。
- Cont–Kukanov 的单场所最优拆分为 $L^{*}=F^{-1}\!\big(\frac{2h+f+r}{\lambda_u+h+r+\theta}\big)-Q$、$M^{*}=S-L^{*}$，它是队列流出量分布的一个分位数，依赖于完整分布，且限价单容量有界。
- 跨场所时最优点使欠交概率相等并刻意超额预订，把"幻影流动性"解释为风险分散而非操纵。
- 队列位置有可度量的价值：挂单价值等于成交概率乘溢价减去逆向选择成本，BAC 上队首比平均位置多 0.21–0.26 tick。
- 最优显示量使"被看见的暴露冲击"与"被看见换来的时间优先"相等；被识破的冰山单会吸引市价单，且已成交越多、价格冲击越小。
- 隐藏并非免费：拆单会被识破且被认为比同等人类订单更具冲击力，而高频交易的隐藏单是小额、贴盘口、信息含量最低的。
- 暗池与隐藏单是替代品，对成交量、深度与价差的反应不同；加入暗池可能抬高价差，却仍能改善价格发现。
- 可观测的清算需求会招致掠夺性抢跑与价格过冲，因此隐藏方向与规模是理性的；订单流毒性可通过 VPIN 实时度量。
