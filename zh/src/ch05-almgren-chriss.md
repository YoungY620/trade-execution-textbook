# Almgren–Chriss 框架

第 4 章把实施差额定义成一个随机量：一笔单子最终花多少钱，取决于挂单期间价格走到了哪里。于是交易者同时面对两件事——已经成交部分的交易成本，以及尚未成交部分的价格风险。Almgren 与 Chriss（2000）把这一观察提炼成最经典的执行模型：在整条调度曲线上做优化，最小化"期望成本 + 方差的惩罚"。本章给出他们的模型、闭式最优轨迹和有效前沿，并交代 Bertsimas 与 Lo（1998）那个风险中性的前身——方差惩罚正是从那里推广而来。

## 清算问题

要在固定的期限 $T$ 之前把 $X$ 单位的头寸完全清掉。把时间切成 $N$ 段，每段长度 $\tau = T/N$，节点 $t_k = k\tau$（$k = 0,\dots,N$）。**交易轨迹**是一串 $x_0,\dots,x_N$，$x_k$ 表示 $t_k$ 时刻仍持有的单位数，起点 $x_0 = X$，终点 $x_N = 0$。等价地，也可以用**交易清单** $n_1,\dots,n_N$ 描述，

$$n_k = x_{k-1} - x_k$$

即在 $t_{k-1}$ 到 $t_k$ 之间卖出的单位数；两者由 $x_k = X - \sum_{j=1}^{k} n_j = \sum_{j=k+1}^{N} n_j$ 联系。**静态**策略在交易开始前就把整张清单定死，只用到 $t_0$ 时点的信息；**动态**策略允许 $n_k$ 依赖 $t_{k-1}$ 之前观察到的一切。所有区间取等长只是为了记号方便，下文每个结果都可以直接取连续时间极限 $N\to\infty$、$\tau\to0$。

## 价格与冲击模型

证券价格同时携带外生的波动和内生的冲击：

$$S_k = S_{k-1} + \sigma\tau^{1/2}\xi_k - \tau\,g\!\left(\frac{n_k}{\tau}\right), \qquad k=1,\dots,N. \tag{1}$$

$\sigma$ 是波动率，$\xi_k$ 独立同分布、零均值、单位方差，$g(\cdot)$ 是**永久冲击**，自变量是区间内的平均成交速率 $v = n_k/\tau$。永久冲击会改变后续交易看到的价格。式 (1) 里没有漂移项，等于假设我们对未来价格方向没有任何信息。此外还有一项**暂时冲击** $h(\cdot)$，只作用在本区间卖出的单位上，不进入下一个市场价：

$$\tilde S_k = S_{k-1} - h\!\left(\frac{n_k}{\tau}\right). \tag{2}$$

暂时冲击刻画的是：为了吃穿不同价位的流动性、把单子做完而付出的价格让步；它被假定会消退，下一区间又从未受冲击的均衡价重新开始。

把每笔成交数量乘以成交价再求和，得到一条轨迹的**捕获**（capture）：

$$\sum_{k=1}^{N} n_k \tilde S_k = X S_0 + \sum_{k=1}^{N}\left(\sigma\tau^{1/2}\xi_k - \tau g\!\left(\frac{n_k}{\tau}\right)\right)x_k - \sum_{k=1}^{N} n_k h\!\left(\frac{n_k}{\tau}\right). \tag{3}$$

交易成本就是初始市值与捕获之差 $XS_0 - \sum_k n_k\tilde S_k$；它正是事后交易成本的标准度量，也基本就是 Perold（1988）所说的实施差额。在交易开始前它是一个随机变量，均值与方差为

$$E(x) = \sum_{k=1}^{N} \tau x_k\, g\!\left(\frac{n_k}{\tau}\right) + \sum_{k=1}^{N} n_k\, h\!\left(\frac{n_k}{\tau}\right), \qquad V(x) = \sigma^2 \sum_{k=1}^{N} \tau x_k^2. \tag{4,5}$$

$E$ 的单位是美元，$V$ 是美元的平方。$E$ 的第一项是尚未卖出的头寸承受的永久冲击损失，第二项是已成交部分的暂时冲击成本；$V$ 则是持仓暴露期间未对冲头寸的方差。当 $\xi_k$ 服从正态时成本严格服从正态，$N$ 大时也近似正态。

## 线性冲击特例

要拿到闭式解，得把 $g$、$h$ 取成对速率的线性函数：

$$g(v) = \gamma v, \qquad h\!\left(\frac{n_k}{\tau}\right) = \epsilon\,\mathrm{sgn}(n_k) + \frac{\eta}{\tau}n_k. \tag{6,7}$$

$\gamma$ 是**永久冲击系数**，单位是（美元/股）/股：不论快慢，卖出 $n$ 单位都会把每股价格压低 $\gamma n$。$\epsilon$ 是暂时成本里的固定部分，单位是美元/股，合理的估计是买买卖价差的一半加上费用。$\eta$ 是**暂时冲击系数**，单位是（美元/股）/（股/时间）；它最难估计，因为它依赖瞬态的微观结构，而且这里恰恰是线性近似最可疑的地方。把 (6,7) 代进 (4)，

$$E(x) = \tfrac12\gamma X^2 + \epsilon\sum_{k=1}^{N}|n_k| + \frac{\tilde\eta}{\tau}\sum_{k=1}^{N} n_k^2, \qquad \tilde\eta = \eta - \tfrac12\gamma\tau. \tag{8}$$

带波浪号的 $\tilde\eta$ 吸收了离散化对永久冲击时点处理的不精确，它与 $\eta$ 相差一个 $O(\tau)$ 修正，$\tau\to0$ 时 $\tilde\eta\to\eta$。当且仅当 $\tilde\eta>0$ 时该式是凸的；而在纯卖出或纯买入这类所有 $n_k$ 同号的情形，$\epsilon\sum|n_k| = \epsilon|X|$。由于 $E$ 被拆成一个常数项、一个与成交量线性相关的项，以及一个对每段成交量平方的惩罚，这个模型有时也被叫作二次成本模型。

两条极端轨迹界定了可达范围。按恒定速率卖出，

$$n_k = \frac{X}{N}, \qquad x_k = (N-k)\frac{X}{N}, \tag{9}$$

得到

$$E = \tfrac12\gamma X^2 + \epsilon X + \left(\eta - \tfrac12\gamma\tau\right)\frac{X^2}{T}, \qquad V = \tfrac13\sigma^2 X^2 T\left(1-\frac{1}{N}\right)\left(1-\frac{1}{2N}\right), \tag{10,11}$$

这是**最小冲击**轨迹：期望成本最低，但期限越长方差越大。另一极端是第一段就把头寸全部卖掉（$n_1 = X$，$x_1=\dots=x_N=0$），此时

$$E = \epsilon X + \eta\frac{X^2}{\tau}, \qquad V = 0. \tag{12,13}$$

方差为零是因为头寸只存在了一瞬，而整块头寸的暂时成本达到了最大。有意思的轨迹都落在两者之间。

## 目标函数：期望成本加方差惩罚

一条策略是**有效**的，如果不存在另一条策略能在方差不高、期望成本也不高的情况下把其中一项做得更好——等价地说，不存在方差相同或更低、期望成本却更低的策略。有效策略集合由约束问题生成：

$$\min_{x:\,V(x)\le V_*} E(x), \tag{14}$$

由于 $V(x)$ 凸、$E(x)$ 严格凸，对每个方差预算 $V_*$ 都存在唯一解 $x^*(V_*)$。用拉格朗日乘子 $\lambda$ 求解它，等价于解无约束问题

$$\min_x \left(E(x) + \lambda V(x)\right). \tag{15}$$

当 $\lambda>0$ 时目标严格凸、有唯一极小点 $x^*(\lambda)$；让 $\lambda$ 在 $[0,\infty)$ 上变动，这些极小点就扫出整条前沿。乘子有直接含义：$\lambda$ 衡量方差相对于期望成本被惩罚得有多重。这是全模型的核心一步。Bertsimas 与 Lo 只最小化 $E$，因此无法区分期望成本相同、风险却不同的两条调度；乘上 $\lambda V$ 正是给风险定价。

## 最优轨迹

由 (8) 和 (5)，目标 $U = E + \lambda V$ 是关于自由持仓 $x_1,\dots,x_{N-1}$ 的严格凸二次型，因此令偏导为零是精确的。对 $j = 1,\dots,N-1$，得到线性差分方程

$$\frac{1}{\tau^2}\left(x_{j-1} - 2x_j + x_{j+1}\right) = \tilde\kappa^2 x_j, \qquad \tilde\kappa^2 = \frac{\lambda\sigma^2}{\tilde\eta} = \frac{\lambda\sigma^2}{\eta\left(1 - \dfrac{\gamma\tau}{2\eta}\right)}. \tag{16}$$

其解是 $\exp(\pm\kappa t_j)$ 的组合，其中 $\kappa$ 满足 $\tfrac{2}{\tau^2}\left(\cosh(\kappa\tau)-1\right) = \tilde\kappa^2$。再加上边界条件 $x_0 = X$、$x_N = 0$，挑出的就是**双曲正弦轨迹**：

$$x_j = \frac{\sinh\!\left(\kappa(T-t_j)\right)}{\sinh(\kappa T)}\,X, \qquad j = 0,\dots,N, \tag{17}$$

对应的交易清单

$$n_j = \frac{2\sinh\!\left(\tfrac12\kappa\tau\right)}{\sinh(\kappa T)}\cosh\!\left(\kappa\left(T - t_{j-\frac12}\right)\right)X, \qquad j = 1,\dots,N, \tag{18}$$

其中 $t_{j-\frac12} = \left(j-\tfrac12\right)\tau$。(16) 里的波浪号同样是 $O(\tau)$ 修正，所以区间很短时

$$\kappa \sim \sqrt{\frac{\lambda\sigma^2}{\eta}} + O(\tau), \qquad \tau\to 0. \tag{19}$$

成交速率是 $v(t) = -\dot x(t)$，正比于 $\cosh(\kappa(T-t))$：开头最快，越接近期限越慢。当 $X>0$ 时每个 $n_j$ 都为正，也就是说卖出大宗头寸的最优解绝不会回头买入——一旦引入漂移或序列相关，这个性质就不成立了。最优轨迹的期望成本与方差有闭式表达：

$$E(X) = \tfrac12\gamma X^2 + \epsilon X + \tilde\eta X^2 \frac{\tanh\!\left(\tfrac12\kappa\tau\right)\left(\tau\sinh(2\kappa T) + 2T\sinh(\kappa\tau)\right)}{2\tau^2\sinh^2(\kappa T)}, \tag{20}$$

$$V(X) = \tfrac12\sigma^2 X^2 \frac{\tau\sinh(\kappa T)\cosh\!\left(\kappa(T-\tau)\right) - T\sinh(\kappa\tau)}{\sinh^2(\kappa T)\sinh(\kappa\tau)},$$

在 $\kappa\to0$ 与 $\kappa\to\infty$ 两个极限下，它们分别退化回 (10–13)。

## 半衰期与比较静态

Almgren 与 Chriss 把

$$\theta = \frac{1}{\kappa}$$

称作这笔交易的**半衰期**：头寸衰减到原来的 $1/e$ 所需的时间。有两点值得注意。第一，$\theta$ 不依赖外生给定的期限 $T$，只由价格动态和冲击系数决定。只要交易者是风险厌恶的（$\lambda>0$），半衰期就是有限的；即使没有外部截止时间（$T\to\infty$），头寸仍会以 $\theta$ 这个时间尺度被清掉。它是交易的内在时间尺度。

第二，比值 $\kappa T = T/\theta$ 告诉我们哪股力量在主导。当 $T \gg \theta$——暂时成本很小、波动率或风险厌恶很大——半衰期相对期限很短，大部分交易会在远早于 $T$ 时就完成，若以 $T$ 为横轴看，轨迹会像最小方差那段尖峰 (12)。当 $T \ll \theta$ 时，交易被期限卡住，由暂时冲击主导；$T/\theta\to0$ 时轨迹趋近直线型最小成本策略 (9)。直接从 (19) 读出比较静态：风险厌恶 $\lambda$ 或波动率 $\sigma$ 越大，$\kappa$ 越大、调度越前载；暂时冲击系数 $\eta$ 越大，$\kappa$ 越小、执行被拉得越慢。

有一个推论容易被忽略。在线性冲击下，方差与暂时冲击都随头寸规模按平方增长，于是同一只证券的篮子不论大小，都以完全相同的方式、在相同的时间尺度上被清掉——这与"大篮子流动性更差、应当做得更慢"的直觉相反。Almgren 与 Chriss 把这一点视为线性冲击假设的缺陷，并建议在实践中按规模选取不同的 $\eta$。

## 有效前沿

若以方差为横轴、期望成本为纵轴，有效前沿是一条光滑的凸曲线，在其极小点处可微。这个极小点就是**naïve 策略**——即不看方差、只最小化期望成本的平均切分轨迹 (9)，Bertsimas 与 Lo 证明它在忽略风险时是最优的。在极小点可微，是这套模型最实用的结论：稍稍偏离 naïve 策略，只会带来二阶的期望成本上升，却能换来一阶的方差下降。因此只要交易者有任何程度的风险厌恶，就不应该真的按 naïve 策略交易。这条曲线呈双曲线形，原文用两个坐标系来读它：图 1 以方差对期望损失作图，标出 $\lambda = 10^{-6}$ 的前沿策略，以及它的两个邻居 $\lambda = 2\times10^{-6}$（更急，卖得更快）与 $\lambda = -2\times10^{-7}$（偏好风险，推迟、末尾加速卖出）；图 3 把同一条前沿改画在成本标准差 $\sqrt{V}$ 平面上，此时用于挑选 VaR 最优策略的切线斜率是常数。前沿在极小点处的曲率，是证券流动性的一个度量。

在风险价值视角下，定义置信水平 $p$ 下一步策略的 VaR：

$$\mathrm{VaR}_p(x) = \lambda_v\sqrt{V(x)} + E(x), \tag{22}$$

它是成本只有 $1-p$ 的概率会被超过的那个水平，其中 $\lambda_v$ 是由正态分布反函数确定的标准差倍数，95% 置信度下为 $1.645$。只要手里有这条单参数前沿，最小化 VaR 就退化成一道一维问题；原文把结果称为**流动性调整 VaR**（L-VaR），即在给定期限下任一静态清算策略所能达到的最小 VaR。注意它与均值–方差前沿的不对称之处：记到不确定性头上的成本随头寸规模线性增长，而暂时冲击按平方增长，于是 VaR 最优的调度会让大头寸更接近直线轨迹。

## 校准

原文第 3.4 节给出了一个算例，量纲推演值得照抄一遍。股价 $S_0 = 50$，头寸 $X = 10^6$ 股，市值 5000 万美元。年化波动率 30%、一年 250 个交易日，日波动率为 $0.3/\sqrt{250} = 0.019$，于是 $\sigma = 0.95$，单位是（美元/股）/日的平方根；年化 10% 的涨幅给出 $\alpha = 0.02$，单位是（美元/股）/日。买卖价差为 $1/8$，故固定暂时成本 $\epsilon = 0.0625$ 美元/股。日均成交量为 500 万股。假设成交达到日均量的 1% 就要付出一个价差的冲击，则

$$\eta = \frac{1/8}{0.01 \cdot 5\times10^6} = 2.5\times10^{-6},$$

单位是（美元/股）/（股/日）。再按"成交达到日均量 10% 时价格效应显著、且显著即一个价差"的经验法则，

$$\gamma = \frac{1/8}{0.1 \cdot 5\times10^6} = 2.5\times10^{-7},$$

单位是美元/股²。取风险厌恶 $\lambda = \lambda_u = 10^{-6}$（每美元），得 $\kappa \approx 0.6$/日；若清算期限为一周，则 $\kappa T \approx 3$——一个居中的节奏，既非 naïve 直线，也非最小方差尖峰。若不交易而持有这一周，持仓价值的一个标准差是 $\sigma\sqrt{T} = 2.12$ 美元/股。可以看到，$\sigma$ 从已实现的价格波动读出，而 $\eta$ 与 $\gamma$ 从"冲击相对于成交量占比"的关系读出——这里是每 1% 成交量一个价差，和每 10% 成交量一个价差。

## 模型的薄弱之处

最优轨迹是用静态优化算出来的，因此调度可以在开仓前就定死；其依据是：在独立增量与对称风险惩罚下，策略具有**时间齐次性**（time-homogeneous）。Almgren 与 Chriss 把它证成一条定理：在 $[0,T]$ 上最优的策略，在任意子区间上仍然最优，所以在之后的任何时刻，交易者只是继续原计划，而不会重新优化成另一条轨迹。这是时间**一致性**，而不是后来对均值–方差执行提出批评时所说的"时间不一致"；它依赖的正是"没有序列相关"这一假设。放松该假设正是原文第 4 节的主题：漂移 $\alpha$ 会把目标持仓挪到 $\bar x = \alpha/(2\lambda\sigma^2)$，在上述算例里约为 1100 股（头寸的 0.11%）；序列相关允许交易者在期与期之间搬移切片，但原文估计收益很小——机构规模下每天也就几十美元——且随头寸变大在整体中的占比趋于消失；而可预知的消息事件只让最优策略变成**分段**静态。

有两个模型边界反复出现。式 (6,7) 的线性冲击是能写出指数解的原因；换成非线性 $g$、$h$，框架依然适用，但轨迹要解一个非二次优化，而且上面那条"与规模无关"的性质也随之消失。另外，连续时间极限 $\tau\to0$ 是"至多一种数学上的便利"——这个模型是对限价订单簿的粗粒化描述，而不是对逐笔订单的描述，第 3 章的微观结构正是在这里重新入场。

## 前身：Bertsimas 与 Lo

Almgren 与 Chriss 推广的是 Bertsimas 与 Lo（1998）。后者要在固定期数内执行一个固定块 $S$，求使**期望**成本最小的动态策略，并用随机动态规划求解。他们的价格动态是一个线性冲击的随机游走：

$$P_t = P_{t-1} + h S_t + \varepsilon_t, \qquad h>0, \qquad \mathbb{E}\!\left[\varepsilon_t \mid S_t, P_{t-1}\right] = 0, \tag{2.3}$$

剩余股数 $\nu_t = \nu_{t-1} - S_{t-1}$，$\nu_1 = S$，$\nu_{T+1} = 0$，在约束 $\sum_t S_t = S$ 下最小化 $\mathbb{E}\left[\sum_t P_t S_t\right]$，贝尔曼方程为 $\mathcal{V}_t(P_{t-1},\nu_t) = \min_{S_t}\mathbb{E}_t\left[P_t S_t + \mathcal{V}_{t+1}(P_t,\nu_{t+1})\right]$。结论是一个否定式：恰恰在这条价格动态下，唯一最优解就是 naïve 的平均切分 $S_t^* = S/T$，最优期望成本为 $P_0 S + \tfrac{hS^2}{2}\left(1 + \tfrac{1}{T}\right)$。原因是每期冲击 $hS_t$ 是永久的，每期的取舍完全一样，也不依赖尚未执行的股数，所以各期的边际执行成本相等，切片就该等分；而且累计永久冲击在 $T\to\infty$ 时并不消失，趋于 $hS^2/2$。原文强调这是"相当苛刻、在实证上难以成立"的条件，一旦走出这个条件，naïve 策略按构造就不再最优。若在价格里加入一个序列相关的信息变量 $X_t$，最优执行策略变成剩余股数与信号二者的线性函数 $S^*_{T-k} = d_{w,k}\nu_{T-k} + d_{x,k}X_{T-k}$，其中 $d_{w,k} = 1/(k+1)$；第一项就是 naïve 策略，第二项在信号不可预测（$\rho=0$）时消失。原文的蒙特卡洛实验表明，在至少一种实证上合理的设定下，最优执行策略的成本比 naïve 低约 25% 到 40%。

Bertsimas 与 Lo 的两个缺口，恰好被 Almgren–Chriss 的目标函数补上。他们的交易者是风险中性的——原文明确说期望成本是唯一目标，更高阶矩只在个别特殊情形下才有解析解——所以当两条调度的期望成本相同时，该模型无法区分谁快谁慢；而正因为风险中性，放在 AC 框架里它的半衰期是无穷大，不论流动性如何都以同一速率交易任何篮子。补进 $\lambda V(x)$ 就补上了缺失的风险偏好，双曲正弦轨迹和半衰期随之而来。

## 本章要点

- Almgren–Chriss 问题是在 $[0,T]$ 内清算 $X$ 单位，通过选择持仓轨迹 $x_k$ 最小化 $E(x)+\lambda V(x)$；这里的成本就是 Perold 的实施差额，其均值与方差由式 (4)、(5) 给出。
- 在永久冲击 $\gamma$ 与暂时冲击 $\eta$ 都为线性时，期望成本为 $\tfrac12\gamma X^2 + \epsilon\sum|n_k| + (\tilde\eta/\tau)\sum n_k^2$，其中 $\tilde\eta = \eta - \tfrac12\gamma\tau$，因此大切片被按平方惩罚。
- 最优轨迹满足差分方程 (16)，是双曲正弦路径 $x_j = X\sinh(\kappa(T-t_j))/\sinh(\kappa T)$；连续时间极限下 $\kappa = \sqrt{\lambda\sigma^2/\eta}$。
- 交易的半衰期 $\theta = 1/\kappa$ 与给定期限无关，是只由流动性、波动率和风险厌恶决定的清算内在时间尺度。
- 风险厌恶或波动率越大，调度越前载、半衰期越短；暂时冲击系数越大则越慢；$\kappa T$ 很小趋近线性清算，$\kappa T$ 很大趋近立即清算。
- 有效前沿是一条光滑凸曲线，其极小点是 naïve 平均切分策略；由于那里曲线平坦，用很小的期望成本上升就能换来一阶的方差下降，因此风险厌恶的交易者不应采用 naïve 策略。
- Bertsimas 与 Lo 那个风险中性、线性冲击的动态规划只在苛刻条件下才使 naïve 策略最优，否则最优策略是剩余股数与信息的线性函数；把风险写进 $\lambda V$ 正是 Almgren 与 Chriss 的增量。
- 模型的假设就是它的边界：靠时间齐次性支撑的静态预算调度、使调度选择与规模无关的线性冲击，以及只是便利而非订单簿真实描述的连续时间极限。
